## Reporting a bug

English and Czech reports are welcome. Search existing issues first, then use the Bug report form. Include:

- GearAndStorage and Valheim versions, on both server and client when applicable.
- Whether you play single-player, on a dedicated server or in a player-hosted world.
- What happened, what you expected, and steps to reproduce it.
- Relevant settings, other installed mods and screenshots.
- Relevant client/server `BepInEx/LogOutput.log` files. Remove passwords, tokens and private server details before attaching them.

Please keep one problem per issue. Reply to the existing report if you have the same problem.

## Feature requests

Use the Feature request form to explain the problem you want to solve and the behaviour you would like. Suggestions can be discussed in the issue comments.

This repository is the public support hub. Mod downloads and version history are available on Thunderstore.
